# Frontend — ximEdgar Gym

React 19 + Vite + Tailwind 4 + react-router (HashRouter). Consume la API de `../backend`.

```bash
npm install
npm run dev      # http://localhost:5173 (proxy de /api a http://localhost:8080)
npm run lint
npm run build
```

Consulta el README de la raíz para la estructura de carpetas y los permisos por rol.
